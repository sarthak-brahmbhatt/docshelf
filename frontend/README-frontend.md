# DocShelf frontend

Angular 22 (standalone components, signals, Angular Material M3) served as a web PWA and wrapped by Capacitor 8 for Android. One codebase, two shells.

```
npm start                 # dev server on http://localhost:4200 (proxy: none — set the API URL in Settings or run behind nginx)
npm run build             # production build → dist/frontend/browser
npm test                  # vitest (jsdom), watch mode
npm run test:ci           # vitest, single run
npm test -- --watch=false --browsers=ChromeHeadless   # same specs in a real headless Chrome
npm run lint              # angular-eslint
npm run cap:sync          # ng build && cap sync   (copies the web build into android/)
npm run android           # cap open android       (needs Android Studio)
```

## Layout

```
src/app/
  app.config.ts           providers: router, HttpClient + interceptors, settings preload, Material defaults, service worker
  app.routes.ts           lazy routes → features/<name>/<name>.routes.ts
  app.ts                  root component, renders <app-shell>
  shell/                  AppShellComponent: toolbar + nav rail (desktop) / drawer + bottom bar (phone)
  core/
    api/models.ts         EVERY DTO interface (design v0.1 §8 + build spec §2.5). Feature agents do not edit this file.
    api/api.service.ts    ApiService — one typed method per endpoint, grouped by resource
    api/api-base.ts       apiUrl(), toParams(), isApiRequest()
    api/auth.interceptor.ts   adds Authorization: Bearer <token>
    api/error.interceptor.ts  ProblemDetail → snackbar, 401 → /settings; SILENT_ERRORS context token
    settings/settings.service.ts  apiBaseUrl / apiToken / voiceLanguage signals, persisted (Preferences on native, localStorage on web)
    ui/toast.service.ts   MatSnackBar wrapper (info / success / error)
    platform/             PlatformService, CameraService, SpeechService, RecorderService, NotificationService, CalendarService
  shared/                 LoadingState<T> + helpers, SkeletonComponent, ErrorBannerComponent, EmptyStateComponent,
                          StatusChipComponent, MaskedValueComponent, ConfirmDialogComponent, relativeDate + inr pipes
                          (import from '../../shared')
  features/
    shelf/  document/  family/  reminders/  portfolio/  chat/  audit/  settings/
```

`settings` is complete. Every other feature folder contains `<name>.routes.ts` and a placeholder `<name>-page.component.ts`.

## How a feature agent adds pages

Work **only inside `src/app/features/<name>/`**. Everything you need is already provided:

1. Replace the placeholder page component; keep the class name exported from `<name>.routes.ts` or update the routes file (it is yours). Add child routes there — `app.routes.ts` only knows about `<name>.routes.ts`. Document detail is mounted at `/documents/:id`; the `id` route param is bound to the component's `id` input (`withComponentInputBinding` is on).
2. Data access: `inject(ApiService)` and call the typed method. All request/response types come from `core/api/models.ts`. If a DTO is missing, do not add it to `models.ts` — define it locally in your feature and report it.
3. Page state: use `LoadingState<T>` from `shared`:

   ```ts
   readonly docs = signal<LoadingState<PageResponse<Document>>>(idle());
   load() {
     this.docs.set(loading(this.docs().data));
     this.api.listDocuments(q).subscribe({
       next: (page) => this.docs.set(ready(page)),
       error: (e) => this.docs.set(failed(e, this.docs().data)),
     });
   }
   ```

   or `toSignal(toLoadingState(this.api.listDocuments(q)))`. Render `<app-skeleton>` while loading, `<app-error-banner [message]="s.error" (retry)="load()">` on error, `<app-empty-state>` when empty.
4. Errors: the interceptor already shows a snackbar for every failed API call and redirects on 401. Pass `{ silent: true }` (or set `SILENT_ERRORS` on the HttpContext) when you handle the error yourself.
5. Uploads: `api.uploadDocument(file, opts)` and `api.createVoiceDocument(blob, mime, opts)` emit `HttpEvent<Document>` — switch on `HttpEventType.UploadProgress` / `Response`. A `409` duplicate arrives as an error whose body is the existing `Document`.
6. Sensitive fields: render with `<app-masked-value [masked]="f.numberMasked" label="Aadhaar number" [reveal]="() => api.revealField(doc.id, 'number')">`; it shows the value for `displaySeconds` (30 s) then re-masks.
7. Confirmations: `await confirm(this.dialog, { title, message, destructive: true })`.
8. Toasts: `inject(ToastService).success('Saved')`.
9. Styling: Material system variables only (`var(--mat-sys-primary)` etc.), the theme follows the OS light/dark setting. Page title: `<h1 class="page-title">`.
10. Tests: vitest with Angular TestBed (`describe/it/expect/vi` are globals). `fakeAsync` is not available under vitest — use `vi.useFakeTimers()` and `await`. Add `*.spec.ts` next to your components; run `npm run test:ci`.

## Platform services (core/platform)

All methods are safe on both platforms; native calls are guarded and failures come back as return values, never as uncaught errors.

| Service | Web | Native (Android) | API |
|---|---|---|---|
| `PlatformService` | — | — | `isNative()`, `platform()`, `isAndroid()`, `hasPlugin(name)`, `info()` |
| `CameraService` | `<input type=file accept=image/* capture=environment>` | `@capacitor/camera` `takePhoto` / `chooseFromGallery` | `takePhoto()`, `pickImage()` → `{ok, file, source}` \| `{ok:false, reason}`; `pickFiles({accept, multiple})` → `{ok, files}` |
| `SpeechService` | Web Speech API (`webkitSpeechRecognition`) | `@capacitor-community/speech-recognition` | signals `state` ('unsupported'\|'idle'\|'listening'\|'error'), `transcript`, `supported`, `listening`; `start(lang?)`, `stop()`, `onResult(cb)` → unsubscribe. Uses `SettingsService.voiceLanguage` by default |
| `RecorderService` | `MediaRecorder` (webm/opus) | `capacitor-voice-recorder` (aac) | signals `state`, `supported`, `recording`; `start()`, `stop()` → `{ok, blob, mimeType, durationMs}`, `cancel()` |
| `NotificationService` | Web Notifications + in-tab timers (best effort) | `@capacitor/local-notifications` | `scheduleReminders(reminders)` (idempotent: id = FNV-1a hash of the reminder uuid, cancels + re-schedules, skips past/non-pending), `schedule(specs)`, `cancel(key)`, `cancelAll()`, `pendingCount()`, `requestPermission()`, signal `permission` |
| `CalendarService` | `{supported:false}` — show a disabled button with `unsupportedHint()` | `@ebarooni/capacitor-calendar` `createEventWithPrompt` | `isSupported()`, `createEventWithPrompt({title, startAt, endAt?, notes?, allDay?})` → `{supported, ok, eventId?, reason?}` |

Typical flows:

- Voice command (chat mic): `speech.onResult(r => composer.set(r.text)); await speech.start();` … `await speech.stop()`. If `speech.supported()` is false, fall back to `recorder.start()` / `recorder.stop()` → `api.transcribe(blob, mimeType, settings.voiceLanguage())`.
- Voice note: `recorder.start()` → `recorder.stop()` → `api.createVoiceDocument(blob, mimeType, {memberId})`.
- Chat `clientActions`: `SCHEDULE_NOTIFICATION` → `notifications.schedule([{key: a.reminderId, title: a.title, body: a.body ?? '', at: a.at}])`; `ADD_CALENDAR_EVENT` → `calendar.createEventWithPrompt({title: a.title, startAt: a.startAt, endAt: a.endAt, notes: a.notes})`.
- Reminders "Sync to phone": `notifications.scheduleReminders(remindersForNext30Days)`.

## Settings / connectivity

- Web (Docker): `apiBaseUrl` stays `''` — requests go to `/api/v1/...` on the same origin and nginx proxies to `backend:8080`.
- Android: the user enters `http://<mac-ip>:8080` and the API token in Settings. `capacitor.config.ts` sets `server.androidScheme = 'http'` + `cleartext: true`, and `AndroidManifest.xml` references `res/xml/network_security_config.xml` so plain http on the LAN is allowed.
- The token is stored in Capacitor Preferences (native) / localStorage (web) and sent as `Authorization: Bearer`.

## Android build (needs Android Studio)

```
npm run cap:sync        # builds the web app and copies it into android/app/src/main/assets/public
npm run android         # opens android/ in Android Studio
```

In Android Studio: let Gradle sync (Capacitor 8 targets compileSdk 36 / minSdk 24 — see `android/variables.gradle`), pick a device or emulator, Run. For a shareable debug APK: Build → Build Bundle(s)/APK(s) → Build APK(s); the file lands in `android/app/build/outputs/apk/debug/`. Permissions declared in the manifest: INTERNET, CAMERA, RECORD_AUDIO, POST_NOTIFICATIONS, SCHEDULE_EXACT_ALARM/USE_EXACT_ALARM, READ/WRITE_CALENDAR, READ_MEDIA_IMAGES. Runtime permission prompts are triggered lazily by the platform services.

The `android/` directory is committed (generated by `npx cap add android`); `android/app/src/main/assets/public` and Gradle outputs are ignored and regenerated by `cap sync`.

## Docker

`Dockerfile` builds with `node:22-alpine` and serves with `nginx:alpine` using `nginx.conf` (SPA fallback, `/api/` and `/actuator/` proxied to `http://backend:8080`, `client_max_body_size 256m`, `proxy_read_timeout 300s`). Build context is the `frontend/` directory.
